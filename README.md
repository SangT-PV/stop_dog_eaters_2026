# Stop Dog Eaters (SDE) — Campaign Repository

Welcome to the central repository for the **Stop Dog Eaters** campaign footprint.

## 🌍 Mission Statement
End the cruel and unregulated dog meat trade in Vietnam and across Asia by combining grassroots advocacy, transparent crowdfunding, AI-powered content operations, and community-led social pressure — anchored by Lucky's story as the human face of the movement.

## 🚀 Where to Start

If you have just cloned this repository, here is what you need to read first:

1. **The Strategic Plan:** Read [`BLUEPRINT.md`](./BLUEPRINT.md) for the complete phase-by-phase execution plan, team role definitions, and success metrics.
2. **Brand & Tone Guidelines:** Read [`BRAND_GUIDELINES.md`](./BRAND_GUIDELINES.md) to understand the core message, tone principles, and visual identity (centered on Lucky's story).
3. **Development / AI Architecture:** Check [`CLAUDE.md`](./CLAUDE.md) for important project constraints, development conventions, and AI instructions.

## 📂 Repository Structure

- `/.planning/` - Project tracking, daily operations reviews, and task tracking.
- `/website/` - Static HTML/CSS/JS and JSON data files for the central hub (stopdogeaters.info).
- `/automation/` - The AI-powered content generation pipeline and publishing scripts (Manus AI, Claude Sonnet, Telegram auto-posting).
- `/pdf_pages/` - Generated PDF assets and research documents.
- `BLUEPRINT.md` - Master campaign orchestrator document.
- `BRAND_GUIDELINES.md` - Guidelines for tone, visuals, and messaging framing.
