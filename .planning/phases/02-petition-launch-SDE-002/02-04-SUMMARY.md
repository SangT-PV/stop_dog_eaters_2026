# Phase 02 Plan 02-04: Prepare Initial Outreach List Summary

**STATUS: IN PROGRESS**

**Planned scope:** Build targeted outreach list for petition promotion across Vietnamese communities, expat groups, and animal welfare organizations.

## Planned Accomplishments

From ROADMAP.md:

1. **Vietnamese Community Outreach**
   - Identify Vietnamese community groups on Facebook, Zalo, Reddit
   - Target Vietnamese diaspora communities (US, Australia, Europe)
   - Find Vietnamese student associations and cultural organizations
   - Map Vietnamese-language social media influencers (pet lovers, health advocates)

2. **Expat Community Engagement**
   - Target expat groups in Vietnam (Facebook groups, forums)
   - English-speaking Vietnam communities (VietnamExpats subreddit, expat forums)
   - International teachers and professionals working in Vietnam
   - Foreign residents with Vietnamese social media following

3. **Animal Welfare Organizations**
   - International: Four Paws, Animals Asia, Humane Society International
   - Vietnamese: ChangeVN, local animal rescue groups
   - Regional: Asia Canine Protection Alliance (ACPA)
   - Social media: Pet influencers, veterinarians, animal welfare advocates

4. **Engagement Strategy**
   - Create outreach templates (email, DM, social post)
   - Define priority tiers (who to contact first, second, ongoing)
   - Set realistic goals (target 1,000 signatures in first week)
   - Establish metrics (track referral sources, engagement rates)

5. **Documentation**
   - Create structured outreach list (Google Sheet or Airtable)
   - Include: Name, Platform, Followers, Contact Method, Priority, Status
   - Add notes on why each target is relevant
   - Track outreach progress (contacted, responded, shared)
