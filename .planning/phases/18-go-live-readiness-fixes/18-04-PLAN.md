**L3 — Dynamic Copyright Year:**

Add the following code inside the `DOMContentLoaded` event listener in `website/js/main.js`, after the existing mobile nav toggle block (after line 17, before the active nav link section):

```javascript
// --- Dynamic copyright year -----------------------------------
const footerYear = document.querySelector('.footer-bottom span');
if (footerYear) {
  footerYear.textContent = footerYear.textContent.replace(/\d{4}/, new Date().getFullYear());
}
```

This approach:
- Targets the first `<span>` inside `.footer-bottom` which contains "&copy; 2026 Stop Dog Eaters..."
- Uses regex replacement so it only changes the 4-digit year, preserving the rest of the text
- Works across all pages since they all share the same footer structure and load main.js
- Gracefully degrades: if JS is disabled, the hardcoded 2026 still shows (acceptable fallback)
- Does NOT require changing the HTML in all 8 files — the JS replacement handles it universally

Do NOT modify the HTML files for this task. The JS approach is cleaner since all pages already load main.js.
