During Plan 999.1-07, password protection was added to admin mode (previously insecure `?admin=true` query param). Now requires password `sde-moderate-2026` (same as moderation dashboard). This prevents unauthorized feature unlocking in production.

It enables the moderation dashboard to publish approved comments/posts directly to filesystem JSON files. **Not required for production** — manual download workflow remains the default until funding justifies a deployed backend.
