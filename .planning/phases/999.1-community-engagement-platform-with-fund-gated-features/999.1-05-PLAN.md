Update `website/js/moderation.js` to handle community post submissions:

1. **`renderPostQueue()`**: Update to read from `localStorage` key `sde-pending-community-posts`. For each pending post, display:
   ```html
   <div class="mod-item mod-post-item" data-id="{id}" data-type="post">
     <div class="mod-item-header">
       <div class="mod-item-meta">
         <strong>{author_name}</strong>
         <span class="mod-item-email">{author_email}</span>
         <span class="mod-item-date">{created_at formatted}</span>
       </div>
       <span class="blog-tag">{tag}</span>
     </div>
     <h4 class="mod-post-title">{title}</h4>
     <div class="mod-item-content">{content preview - first 500 chars with escapeHTML}</div>
     <div class="mod-item-actions">
       <button class="btn btn-primary btn-sm mod-approve-post" data-id="{id}">Approve & Publish</button>
       <button class="btn btn-outline btn-sm mod-reject-post" data-id="{id}">Reject</button>
       <button class="btn btn-outline btn-sm mod-preview-post" data-id="{id}">Preview Full</button>
     </div>
   </div>
   ```

2. **`async approveCommunityPost(postId)`**:
   - Find post in `sde-pending-community-posts` localStorage.
   - Convert to blog post format (per D-05: same structure as AI posts):
     ```javascript
     const blogPost = {
       id: generateSlug(post.title), // kebab-case from title
       title: post.title,
       excerpt: post.content.substring(0, 200) + '...',
       body_html: convertMarkdownToHTML(post.content), // simple conversion
       banner_url: null,
       tag: post.tag || 'Community',
       date: new Date().toISOString().split('T')[0],
       author: post.author_name + ' (Community)'
     };
     ```
   - Save to `localStorage` key `sde-approved-blog-posts` (array). The blog-timeline.js should be able to merge these with server data.
   - Also save to `sde-approved-community-posts` for tracking.
   - Remove from pending queue.
   - Generate downloadable JSON for the index entry and individual post file (same export pattern as comments).

3. **`generateSlug(title)`**: Convert title to kebab-case slug: lowercase, replace spaces/special chars with hyphens, remove consecutive hyphens, trim hyphens, max 80 chars.

4. **`convertMarkdownToHTML(text)`**: Simple converter:
   - `**text**` -> `<strong>text</strong>`
   - `*text*` -> `<em>text</em>`
   - `__text__` -> `<u>text</u>`
   - Double newline -> `</p><p>`
   - Single newline -> `<br>`
   - Wrap in `<p>` tags
   - Apply escapeHTML first, then formatting.

5. **`rejectCommunityPost(postId)`**: Remove from pending, update UI.

6. **`previewPost(postId)`**: Show full content in a modal overlay (simple div with white background, close button, full content rendered).

7. Update the pending count badges on tabs.

8. **Add event delegation** for the new buttons: `.mod-approve-post`, `.mod-reject-post`, `.mod-preview-post`.

Add CSS for preview modal:
```css
.mod-preview-modal { position: fixed; top: 0; left: 0; right: 0; bottom: 0; background: rgba(0,0,0,0.5); z-index: 1000; display: flex; align-items: center; justify-content: center; padding: 24px; }

```
