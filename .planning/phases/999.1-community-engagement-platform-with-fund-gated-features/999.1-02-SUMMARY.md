# Phase 999.1 Plan 02: Fund-Gated Roadmap and Celebration Banner — COMPLETE

**One-liner:** Vertical roadmap timeline on token.html shows 4 funding tiers with state-based styling; celebration banner on homepage announces unlocks.

## Objective

Implement the fund-gated roadmap timeline on token.html and the celebration hero banner on the homepage. The roadmap provides transparent visual incentive to donate by showing which community features are unlocked and what remains. The celebration banner creates high-visibility announcements when milestones are reached.

## Key Decisions Made

1. **State-based rendering approach:** Determined tier state (completed/current/locked) dynamically based on `current_unlocks` rather than hardcoding. This allows real-time updates as funding grows without code changes.

2. **Current goal logic:** First tier with `unlocked=false` is always the "current" goal. This ensures the roadmap always highlights the next achievable milestone, even if multiple tiers are unlocked simultaneously.

3. **Progress bar gradient:** Used `linear-gradient(90deg, #2A9D8F, #E63946)` to visually blend "completed" (teal) and "current" (red) states, reinforcing the connection between progress and urgency.

4. **Single module pattern:** Combined roadmap and celebration banner logic in one `fund-roadmap.js` file. The static method pattern allows homepage to use banner logic without instantiating full roadmap class.

5. **Auto-dismiss on expiry:** Banner checks `expires_at` date and auto-hides when expired, preventing stale celebration messages from displaying indefinitely.
