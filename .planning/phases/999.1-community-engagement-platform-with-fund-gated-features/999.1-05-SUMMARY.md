**Community post submission form with $2.5K tier gating, moderation dashboard integration, and automatic blog format conversion with export functionality**

## Accomplishments

- Community post submission form appears on blog.html with automatic $2.5K tier gating
- Locked state displays progress bar with current funding ($0 of $2,500) and donate CTA
- Unlocked state shows full form: name, email, title, topic selector, content editor with formatting toolbar
- Form validation: name 1-100 chars, valid email regex, title 5-200 chars, topic required, content 100-5000 chars
- Submissions saved to localStorage as 'sde-pending-community-posts' for moderation pickup
- Moderation dashboard Posts tab now shows pending community posts with 500-char preview
- Approve button converts submission to blog post format with slug generation, excerpt creation, markdown-to-HTML conversion
- Approved posts saved to 'sde-approved-blog-posts' localStorage key for immediate blog feed display
- Preview modal shows full content with formatting before approval decision
- Export generates downloadable JSON files (index entry + individual post) for git commit
- Reject button removes from pending queue with fade-out animation

## Decisions Made

- **Blog format conversion:** Approved community posts use same structure as AI posts with `author: "Name (Community)"` tag per decision D-05
- **localStorage keys:** `sde-pending-community-posts` for submissions, `sde-approved-blog-posts` for approved posts, `sde-approved-community-posts` for tracking
- **Slug generation:** Kebab-case conversion with special char removal, consecutive hyphen replacement, max 80 chars
- **Markdown conversion:** Simple patterns for **bold**, *italic*, __underline__, double newline → `<p>`, single newline → `<br>`
- **Export files:** Generate 2 JSON files (index entry for data/index.json, individual post for data/posts/) to maintain existing blog architecture
- **Preview modal:** Full-screen overlay with close button (X, click outside, or Escape key) for content review before approval
