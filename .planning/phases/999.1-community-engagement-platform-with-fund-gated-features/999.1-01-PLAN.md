**A. Create `website/js/comments.js`** — A read-only comment rendering module (submission form comes in Plan 03).

Follow the same class-based module pattern as `fund-tracker.js`. The module must:

1. **Class: `CommentSection`** with constructor accepting `(postSlug, configUrl='data/community-config.json')`.

2. **`async init()`**: Fetch community-config.json. Check if `current_unlocks.comments === true`. If locked, call `renderLocked()`. If unlocked, fetch `data/comments/{postSlug}-comments.json` and call `renderComments()`.

3. **`renderLocked()`**: Display a locked-state card (per D-19 empty state):
   ```html
   <div class="comments-locked">
     <div class="comments-locked-icon"><!-- lock SVG icon --></div>
     <h3>Discussion Section Unlocks at $1K</h3>
     <p>When our campaign reaches $1,000 in funding, blog discussions will be enabled for everyone. Help us get there!</p>
     <a href="donate.html" class="btn btn-primary">Support the Campaign</a>
     <div class="comments-locked-progress">
       <div class="comments-locked-bar" style="width: {percent}%"></div>
     </div>
     <span class="comments-locked-amount">${current} of $1,000 raised</span>
   </div>
   ```
   Read `data/funds.json` to get `summary.total_raised` and calculate progress percentage toward $1,000.

4. **`renderComments(comments)`**: Build threaded comment tree. Implementation:
   - Build a tree from flat array: group by `parent_id` (null = root). Max nesting depth: 3 levels (Claude's discretion).
   - Only render comments with `status === 'approved'`.
   - For each comment, generate HTML with these elements (per D-06, D-07, D-09, D-10):
     - **Avatar**: Colored circle with first letter of `author_name`, uppercase. Background color generated from name hash using brand palette (rotate through: `#2A9D8F`, `#E63946`, `#264653`, `#E8A838`, `#1d6a72`, `#c0392b`).
     - **Author name** in bold (font-weight: 700).
     - **Timestamp**: Relative time ("2 hours ago", "3 days ago") using a simple `timeAgo()` helper.
     - **Content**: Plain text with `escapeHTML()` applied (same pattern as blog-timeline.js). Newlines converted to `<br>`.
     - **Like button**: Heart icon + count. Clicking increments locally (no persistence in this plan — just visual). Use `<button class="comment-like-btn" data-id="{id}">` with SVG heart icon.
     - **Reply button**: `<button class="comment-reply-btn" data-id="{id}">Reply</button>` — clicking does nothing in this plan (submission form in Plan 03).
   - Nested replies indented with `margin-left: 32px` per level, with a left border line (`border-left: 2px solid var(--border)`).
   - Empty state when no comments: "No comments yet. Be the first to share your thoughts!"

5. **`escapeHTML(str)`**: Same implementation as blog-timeline.js (create div, set textContent, return innerHTML).

6. **`timeAgo(isoString)`**: Returns relative time strings:
   - < 60 seconds: "just now"
   - < 60 minutes: "{n} minutes ago"
   - < 24 hours: "{n} hours ago"
   - < 7 days: "{n} days ago"
   - < 30 days: "{n} weeks ago"
   - else: formatted date (e.g., "Mar 24, 2026")

7. **`getAvatarColor(name)`**: Hash the name string and return one of 6 brand colors.

8. **Auto-initialize** on DOMContentLoaded:
   ```javascript
   document.addEventListener('DOMContentLoaded', () => {
     const container = document.getElementById('comments-section');
     if (container) {
       const params = new URLSearchParams(window.location.search);
       const postSlug = params.get('id');
       if (postSlug && /^[a-z0-9\-]+$/i.test(postSlug)) {
         const section = new CommentSection(postSlug);
         section.init();
         window.commentSection = section;
       }
     }
   });
   ```
