# Phase 999.1: Community Engagement Platform with Fund-Gated Features - Context

**Gathered:** 2026-03-24
**Status:** Ready for planning

<domain>
## Phase Boundary

Transform passive blog readers into active community participants through fund-gated features that unlock at transparent funding milestones:
- **$1K tier:** Blog discussion sections (comments, moderation, threading)
- **$2.5K tier:** Community post creation (user-generated content with approval workflow)
- **$5K tier:** AI engagement bot (auto-responds with brand voice)
- **$10K+ tier:** Feature voting system (community decides priorities)
- **Always visible:** Fund-gated roadmap showing progress toward each tier

This phase delivers the complete community engagement platform with tier-based unlocking integrated into the existing website.

</domain>

<decisions>
## Implementation Decisions

### Storage & Authentication
- **D-01:** Comment and community post storage uses JSON files (match existing blog pattern: `data/posts/`, `data/comments/`)
- **D-02:** No database required for MVP. Simple, no hosting complexity. Designed for <1000 comments scale.
- **D-03:** User authentication is name + email only (no passwords, no OAuth). Matches petition form pattern. Email validation only.
- **D-04:** Comment JSON files stored in `website/data/comments/{post-slug}-comments.json` (parallel structure to posts)
- **D-05:** Approved community posts use same data structure as AI-generated posts, stored in `data/posts/` with `author: 'Community'` tag. Renders in same blog feed (`blog.html` reuses existing rendering logic).

### Comment UI & Moderation
- **D-06:** Visual/UX reference: React component (comment-reply.tsx) adapted to vanilla HTML/CSS/JS (no React migration)
- **D-07:** Implement threaded replies (Reddit-style nested comments) with visual nesting
- **D-08:** Include formatting toolbar (bold, italic, underline, emoji) - requires markdown or HTML sanitization
- **D-09:** Include like/heart button per comment (stored in comment JSON, simple engagement metric)
- **D-10:** Include user avatars (SVG icons or initials) - generate from name (first letter circles) or default icon
- **D-11:** Moderation policy: Approve-first for ALL content (comments and community posts go to queue before appearing publicly). Tuan Anh approves before public display. Safer but slower.
- **D-12:** Moderation interface: Simple HTML moderation page (`moderate.html`) with pending content list, Approve/Reject buttons, password-protected. Matches plain HTML architecture.

### AI Bot Behavior
- **D-13:** Bot trigger: Selective responses based on keywords ('rabies', 'regulation', etc.) or sentiment (questions, negative sentiment). Avoids spam, more thoughtful than responding to every comment.
- **D-14:** AI model: Claude Haiku (already integrated in `automation/clients/claude_client.py` for blog generation). Fast, cost-effective ($0.25/million tokens), consistent with existing automation.
- **D-15:** Rate limiting: Max 3 bot responses per blog post (across all comment threads). Prevents spam, balanced engagement.
- **D-16:** Brand voice: Use existing `BRAND_GUIDELINES.md` for system prompt (Educational, Sensitive, Data-Driven tone). No need to wait for Phase 5 content pillars. May refine later.

### Fund-Gating Visual Design
- **D-17:** Fund-gated roadmap location: Dedicated section on `token.html` (extends existing fund tracker). Centralized, matches fund tracker context.
- **D-18:** Visual style: Vertical timeline/roadmap showing funding journey. Past milestones = completed, current = highlighted, future = dimmed. More narrative than progress bars.
- **D-19:** Tier unlock celebration: Hero banner on homepage ("🎉 We raised $X! Comments now enabled"). Temporary (1 week), then fades. High visibility, immediate communication.
- **D-20:** Brand color mapping: Safety Teal (#2A9D8F) for completed milestones, Urgency Red (#E63946) accent for current fundraising goal, Deep Slate/Gray (#264653) for locked future tiers. Matches brand color theory (Authority + Urgency).

### Claude's Discretion
- Exact threading depth limit (e.g., max 3 levels of nesting)
- HTML sanitization library choice (DOMPurify already used in `post.html`)
- Moderation page password implementation (simple .htaccess vs JavaScript check)
- AI bot keyword list refinement (start with obvious terms, expand based on usage)
- Timeline visual implementation details (SVG, CSS, or JavaScript animation library)
- Empty state messages for comments section before $1K unlocked

</decisions>
