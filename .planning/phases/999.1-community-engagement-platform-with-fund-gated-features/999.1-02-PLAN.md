2. **`renderRoadmap()`**: Build a vertical timeline (per D-18) with 4 milestones. For each tier in order (`comments`, `community_posts`, `ai_bot`, `feature_voting`):

   Determine state:
   - `completed`: `current_unlocks[tierKey] === true`
   - `current`: NOT unlocked AND is the first unlocked=false tier (the next goal)
   - `locked`: NOT unlocked AND NOT the current goal

   Generate HTML for each milestone:
   ```html
   <div class="roadmap-milestone roadmap-{state}" data-tier="{tierKey}">
     <div class="roadmap-connector">
       <div class="roadmap-dot"></div>
       <div class="roadmap-line"></div>
     </div>
     <div class="roadmap-content">
       <div class="roadmap-amount">{label}</div>
       <h3 class="roadmap-feature">{feature name}</h3>
       <p class="roadmap-description">{description}</p>
       {if state === 'current':}
       <div class="roadmap-progress">
         <div class="roadmap-progress-bar" style="width: {percent}%"></div>
       </div>
       <span class="roadmap-progress-text">${currentRaised} of ${thresholdAmount} raised</span>
       {endif}
       {if state === 'completed':}
       <span class="roadmap-badge">Unlocked</span>
       {endif}
       {if state === 'locked':}
       <span class="roadmap-badge roadmap-badge-locked">Locked</span>
       {endif}
     </div>
   </div>
   ```

**A. Add celebration banner logic to `website/js/fund-roadmap.js`** (per D-19):

Add a static method or separate initialization block that handles the celebration banner on the homepage:

```javascript
// Add to FundRoadmap class or as standalone function
static async initCelebrationBanner() {
  const banner = document.getElementById('celebration-banner');
  if (!banner) return;

  try {
    const response = await fetch('data/community-config.json');
    const config = await response.json();
    const cb = config.celebration_banner;

    if (!cb.active) { banner.style.display = 'none'; return; }

    // Check expiry
    if (cb.expires_at && new Date(cb.expires_at) < new Date()) {
      banner.style.display = 'none';
      return;
    }

    // Show banner
    banner.innerHTML = `
      <div class="celebration-content">
        <span class="celebration-emoji">&#127881;</span>
        <div>
          <strong class="celebration-title">${escapeHTML(cb.message)}</strong>
          <span class="celebration-feature">${escapeHTML(cb.tier_unlocked)} is now live!</span>
        </div>
        <button class="celebration-close" aria-label="Dismiss">&times;</button>
      </div>
    `;
    banner.style.display = 'block';

    // Dismiss handler
    banner.querySelector('.celebration-close').addEventListener('click', () => {
      banner.style.display = 'none';
    });
  } catch (e) {
    banner.style.display = 'none';
  }
}
```

Add `escapeHTML` helper if not already in scope (same pattern as blog-timeline.js).
