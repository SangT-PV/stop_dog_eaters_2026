## Technical Decisions

### Feature Voting
- **Storage:** localStorage (`sde-votes`) - simple key-value pairs
- **Email hashing:** Basic string hash (not cryptographic) - MVP simplicity
- **Vote toggling:** Click button again to remove vote
- **Rate limiting:** None (client-side only) - add server validation later

### Blog Integration
- **Merge strategy:** Server posts + localStorage approved posts
- **Deduplication:** By ID, server version wins
- **Badge styling:** Purple `.community-badge` next to tag
- **Performance:** No impact - localStorage is fast, small dataset

### Admin Mode Security
- **Password:** Same as moderation (`sde-moderate-2026`)
- **Storage:** sessionStorage (clears on browser close)
- **Scope:** All pages that load admin-utils.js
- **Indicator:** Red banner with exit button

### API Server Architecture
- **Framework:** Flask (lightweight, easy to run)
- **CORS:** Enabled for file:// protocol (local HTML files)
- **Security:** Localhost-only (127.0.0.1), no authentication needed
- **Deployment:** NOT deployed - local dev tool only
