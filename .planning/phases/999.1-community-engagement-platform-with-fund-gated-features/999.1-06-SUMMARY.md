# Phase 999.1 Plan 06: AI Engagement Bot Summary

**One-liner:** Built AI engagement bot with Claude Haiku that auto-responds to blog comments using SDE brand voice, keyword/sentiment triggers, rate limiting (max 3 per post), and $5K tier gating

## What Was Built

### Task 1: AI Bot Response Module

**Created `automation/clients/ai_bot.py` (247 lines):**

**Core Module Architecture:**
- Imports existing `claude_client.py` Bedrock configuration (AWS_PROFILE, AWS_REGION, BEDROCK_MODEL_ID)
- Uses same `anthropic.AnthropicBedrock` client for consistency
- Model: `us.anthropic.claude-haiku-4-5-20251001-v1:0` (same as blog synthesis)

**Configuration:**
```python
BOT_NAME = 'SDE Bot'
BOT_EMAIL = 'bot@stopdogeaters.info'
MAX_RESPONSES_PER_POST = 3  # Per D-15 (rate limiting)
```

**Trigger Logic (Per D-13 — Keyword/Sentiment-Based):**

1. **Keyword Triggers (26 keywords):**
   - Health: `rabies`, `regulation`, `slaughterhouse`, `health`, `disease`
   - Action: `petition`, `sign`, `help`, `what can i do`, `how can i help`
   - Context: `vietnam`, `government`, `law`, `ban`, `cruelty`
   - Trade: `stolen`, `pet theft`, `trade`, `market`
   - Stats: `statistics`, `data`, `survey`, `95%`, `5 million`
   - Campaign: `lucky`, `dog`, `animal welfare`

2. **Question Detection:**
   - Regex: `\?|how|why|what|when|where|is it true|can you|could`
   - Responds to user questions with factual answers

3. **Negative Sentiment Detection:**
   - Regex: `terrible|awful|horrible|disgusting|angry|furious|heartbreaking|sad|devastat`
   - Validates frustration, redirects to action

**System Prompt (Per D-16 — Brand Voice from BRAND_GUIDELINES.md):**
```
Brand Voice: Educational, Sensitive, Data-Driven.
Tone Rules:
- Never sensationalize cruelty for shock value
- Lead with empathy, close with data
- Use active, direct language; avoid passive constructions
- Always frame as locally led — 95% of Vietnamese support this change
- Public safety angle is as valid as animal welfare angle

Key Facts you may cite:
- 5 million dogs killed annually in Vietnam
- 95% of Vietnamese (2021 survey) support ending the trade
- Zero registered slaughterhouses — completely unregulated
- Health risks: rabies, E. coli, Salmonella

Your role: Respond to community comments on blog posts. Keep responses:
- Under 200 words
- Factual and educational
- Encouraging toward action (mention petition: {CHANGE_ORG_URL})
- Warm but not preachy — data speaks, let the audience conclude

If the comment is a question, answer it directly with facts.
If the comment shares a personal story, acknowledge it with empathy.
If the comment expresses frustration, validate the feeling and redirect to action.

Sign off as: — SDE Bot
```

**Functions:**

1. **`should_respond(comment: dict) -> bool`**
   - Checks if comment content matches any trigger keyword (case-insensitive)
   - Checks question pattern with regex
   - Checks negative sentiment pattern with regex
   - Returns `True` if any trigger matches, `False` otherwise

2. **`count_bot_responses(comments: list) -> int`**
   - Counts existing bot responses in comment list
   - Filters by `author_name == 'SDE Bot'` and `status == 'approved'`
   - Used to enforce MAX_RESPONSES_PER_POST limit

3. **`generate_response(comment: dict, post_context: str) -> str`**
   - Calls Claude Haiku via `_client.messages.create()`
   - Max tokens: 512 (sufficient for 200-word responses)
   - Prompt includes: blog post context, comment author name, comment content
   - Returns generated response text or `None` on error

4. **`create_bot_comment(post_slug: str, parent_comment_id: str, response_text: str) -> dict`**
   - Creates comment object matching `data/comments/_schema.json`
   - Auto-generates UUID for `id`
   - Sets `author_name: 'SDE Bot'`, `author_email: 'bot@stopdogeaters.info'`
   - Sets `status: 'approved'` (bot comments are auto-approved)
   - Sets `parent_id` to original comment ID (bot always replies, never top-level)
   - Timestamps: `created_at` and `moderated_at` both set to current UTC time
   - `moderated_by: 'Automated'`

5. **`process_comments_for_post(post_slug: str, post_title: str) -> list`**
   - **Tier-gating check:**
     - Reads `website/data/community-config.json`
     - Checks `current_unlocks.ai_bot` boolean
     - Returns empty list if `False` (feature not unlocked yet)
   - Loads `data/comments/{post_slug}-comments.json`
   - Filters for approved comments only
   - Counts existing bot responses
   - Enforces `MAX_RESPONSES_PER_POST` limit
   - For each approved comment:
     - Skip if author is 'SDE Bot' (don't reply to self)
     - Skip if bot already replied to this comment (check `parent_id`)
     - Skip if `should_respond()` returns `False`
     - Generate response via `generate_response()`
     - Create bot comment object
     - Append to comments array
     - Decrement remaining budget
   - Saves updated comments back to JSON file
   - Returns list of new bot comments generated

6. **`run_bot_for_all_posts()`**
   - Iterates over all `*-comments.json` files in `data/comments/`
   - Calls `process_comments_for_post()` for each post
   - Logs total responses generated
   - Can be run standalone: `python automation/clients/ai_bot.py`

## How It Works (End-to-End Flow)

1. **User submits comment** on `post.html` → saved to `localStorage` as `pending`
2. **Moderator approves comment** in `moderate.html` → saved to `sde-comments-{slug}` localStorage + exports to JSON
3. **Moderator commits JSON** to `website/data/comments/{slug}-comments.json` in repo
4. **Bot run triggered** (manual or scheduled):
   - `python automation/clients/ai_bot.py`
   - OR integrated into daily `pipeline.py` automation
5. **Bot checks tier gating:**
   - Reads `community-config.json`
   - If `current_unlocks.ai_bot == false` → skips (feature locked)
6. **Bot processes each post:**
   - Reads approved comments
   - Checks existing bot response count
   - Filters comments matching trigger keywords or sentiment patterns
   - Generates Claude Haiku response (under 200 words, brand voice)
   - Appends bot comment to JSON file
   - Stops at 3 responses per post
7. **User views post:**
   - `comments.js` loads comments from JSON
   - Detects bot comments by `author_name == 'SDE Bot'`
   - Renders with teal accent, robot avatar, "Bot" badge
   - No reply button on bot comments
