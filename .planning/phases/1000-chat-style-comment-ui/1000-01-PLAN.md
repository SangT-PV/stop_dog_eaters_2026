<objective>
Transform the blog comment UI from a traditional card-based layout to a modern chat/messaging-style interface with speech bubbles, compact headers, and a bottom-anchored input bar. The visual style should feel like a group chat or messaging app (similar to Telegram/WhatsApp), making discussions feel more conversational and engaging.

Purpose: Chat-style UIs feel more natural for discussions. The current card layout looks formal and static. A chat-bubble approach encourages more participation and feels modern.

Output: Updated `comments.js` rendering and `style.css` styles producing a chat-bubble comment interface. All existing functionality preserved (threading, likes, replies, fund-gating, pending badges, bot comments).
</objective>
