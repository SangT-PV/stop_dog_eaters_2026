# Phase 06 Plan 06-04: Publish Transparency Statement Summary

**STATUS: IN PROGRESS**

**Planned scope:** Create and publish comprehensive transparency statement on donate.html that commits to radical transparency in fund management, links specific funds to specific activities, and establishes public accountability framework.

## Planned Accomplishments

From ROADMAP.md:

1. **Transparency Statement Document**
   - Core commitment: "Every dollar publicly tracked, no exceptions"
   - Fund allocation policy (what money will be used for)
   - What funds will NOT be used for (salaries, overhead, personal expenses)
   - Monthly reporting schedule
   - Public accountability mechanisms

2. **Fund-to-Activity Linkage**
   - Media outreach: $8K → specific outlets and campaigns
   - Community organizing: $7K → events, materials, translation
   - Digital advertising: $5K → Facebook, Instagram, TikTok, Zalo
   - Legal advocacy: $3K → Vietnamese legal consultation, petition delivery
   - Technology: $1.5K → website, fund tracker, infrastructure
   - Contingency: $500 → platform fees, emergency needs

3. **Monthly Reporting Commitment**
   - What we'll report: Total raised, total spent, breakdown by category
   - When: First Monday of each month
   - Where: Website (donate.html#reports), Telegram, email to backers
   - Format: Visual dashboard + detailed expense list

4. **Public Accountability Framework**
   - Open book policy: Any backer can request expense receipts
   - Response timeline: Within 48 hours of request
   - Escalation process: If concerned about spending, contact [email]
   - Independent audit: Commit to annual audit if funds exceed $50K

5. **Website Integration**
   - Add transparency section to donate.html (below donation options)
   - Link to fund tracker dashboard
   - Embed recent expenses log (live widget)
   - Display "No Salaries" badge prominently
