| Property | Value |

## Spacing Scale

Declared values (8-point scale from existing design system):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, gaps |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |
| 4xl | 96px | Section vertical padding |

**Exceptions:**
- Touch targets maintain 44px minimum per WCAG AA
- Blog card hover lift: 4px translateY
- Timeline dot pulse radius: 12px

**Source:** Pre-populated from existing CSS variables and brand guidelines. Consistent with Phase 8 refactoring foundation.

|------|------|--------|-------------|-------|

| Heading L | 1.6rem (25.6px) | Montserrat 900 | 1.2 | Article H2 in prose |

## Color

60/30/10 split with semantic category mapping.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` white | Page background, card surfaces |
| Secondary (30%) | `#F8F9FA` mist | Alternate sections, secondary cards |
| Accent Primary (10%) | `#2A9D8F` teal | CTAs, links, tag borders, timeline dots, stat borders |
| Accent Urgency | `#E63946` red | Destructive actions, stat callouts, urgent CTAs |
| Text Primary | `#264653` slate | Headings, main text |
| Text Secondary | `#4a5563` text-md | Body text, excerpts |

**Accent reserved for:**
- Primary CTAs ("Sign the Petition", "Read More")
- Blog tag badge backgrounds (color-coded by category)
- Timeline dots with pulse animation
- Left accent borders on blog cards (4px teal)
- Left accent borders on stat callouts (4px red)
- Link hover states (teal-dk `#1f7a6e`)

**Tag badge color mapping:**
| Category | Background | Text |
|----------|------------|------|
| Public Health | `--red` | `--white` |
| Regulation | `--teal` | `--white` |
| Pet Theft | `--amber` | `--white` |
| Public Support | `--slate` | `--white` |
| Lucky's Story | `--red-lt` | `--white` |
| Campaign Updates | `--teal-lt` | `--white` |

**Image placeholder gradient:** `linear-gradient(135deg, var(--teal), var(--slate))` — conveys brand even without photos.

**Source:** Pre-populated from BRAND_GUIDELINES.md color system and 09-CONTEXT.md decisions D-20, D-21.

## Shadows & Elevation

Dramatic shadow hierarchy for bold activism aesthetic.

| Token | Value | Usage |
|-------|-------|-------|
| `--shadow-sm` | `0 2px 8px rgba(38,70,83,0.07)` | Default card state |
| `--shadow` | `0 4px 24px rgba(38,70,83,0.10)` | Hover state (blog cards) |
| `--shadow-lg` | `0 8px 48px rgba(38,70,83,0.16)` | Dramatic hover (timeline cards) |
| `--shadow-red` | `0 8px 32px rgba(230,57,70,0.25)` | Red CTAs |

**Interaction pattern:**
- Blog cards: `--shadow-sm` default → `--shadow-lg` on hover (0 12px 40px rgba(38,70,83,0.15) per D-01)
- Timeline cards: `--shadow` default → `--shadow-lg` on hover
- CTAs: `--shadow-red` on hover
- Transition: 0.3s ease (D-19)

**Source:** Pre-populated from existing CSS variables and 09-CONTEXT.md decision D-19.

**All card components get `--radius-lg`:**

- `.donate-tier-card`, `.transparency-box`

**Source:** Pre-populated from 09-CONTEXT.md decisions D-11 through D-14. Large rounded corners (2-4rem range) are a core brand guideline.

## Interaction States

| Element | Default | Hover | Active | Focus |
|---------|---------|-------|--------|-------|
| Blog card | `--shadow-sm` | `translateY(-4px)` + `--shadow-lg` (0 12px 40px) | N/A | `outline: 2px solid var(--teal)` |
| Timeline card | `--shadow` | `--shadow-lg` | N/A | `outline: 2px solid var(--teal)` |
| Tag badge | Static | Scale 1.05 | N/A | `outline: 2px solid currentColor` |
| CTA button | Solid teal | `--shadow-red` + scale 1.02 | Scale 0.98 | `outline: 2px solid var(--teal)` |
| Link (in prose) | Teal underline | `color: var(--teal-dk)` | N/A | `outline: 2px solid var(--teal)` |

**Transition timing:** 0.3s ease for all hover effects (300-700ms range per brand guidelines).

**Entrance animations:** Blog cards can optionally use `@keyframes fadeInUp` on scroll (IntersectionObserver, Claude's discretion per 09-CONTEXT.md).
